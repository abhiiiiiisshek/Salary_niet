# NIET Payroll

Generates the monthly **Payroll Excel** and the **Indian Bank Transfer Memo (Word)** from the approved August 2026 templates. Only the monthly values change. Fonts, borders, merged cells, print setup and the letter layout stay exactly as approved.

> **This repo must stay private.** The templates contain every employee's salary and bank account number.

## Monthly use

1. Open the site and sign in.
2. Pick the salary month. Days in the month, the "paid in" month and the default cheque date fill in automatically.
3. Enter C/L, M/L & E/L and **leave without pay** for anyone who took leave. Only leave without pay reduces salary.
4. Check the table, tick the box, and click **Generate payroll and memo**. You get `Payroll_<Month>_<Year>.xlsx` and `Transfer_Memo_<Month>_<Year>.docx`.

The files are built in the browser. Nothing is uploaded or stored on the server.

## Calculation (mirrors the approved sheet)

| | |
|---|---|
| Salary cut | Salary ÷ days in month × leave without pay (Principal: BP + GP + DA; HRA is not cut) |
| ESI | 0.75% of payable salary, only for employees whose row in the template has the ESI formula |
| Net payable | `ROUND(payable − ESI, 0)` per employee, nearest rupee |
| Total | sum of the rounded net amounts, so Excel, memo and words always match |

## Deploy on Vercel

1. vercel.com → **Add New → Project** → import `niet-payroll` from GitHub.
2. Framework preset: **Other**. Leave the build settings alone (`vercel.json` handles them).
3. **Settings → Environment Variables**: add `PAYROLL_USER` and `PAYROLL_PASSWORD` (Production, Preview, Development).
4. Also add `TEMPLATE_KEY` (64 hex characters). It decrypts `api/_sealed.js`. To change employees: edit the private templates, run `node src/seal.mjs`, commit, push.
5. Redeploy. Until the variables are set, the site refuses every visitor (it fails closed).

## Changing employees or salaries

Names, salaries and bank accounts are read from `src/payroll_template.xlsx` and `src/memo_template.docx`. To change them, edit the templates (keep the `{{TOKENS}}` in the memo), run `python3 src/build.py`, then `npm test` and commit. The regression test must still pass for August 2026 unless salaries changed.

## Monthly records (Supabase)

Every **Generate** saves a draft version of that month (both files + the leave entered). One version per month can be **marked final**; the database enforces this with a unique index, so a month can never have two finals. A final month is locked. **Reopen** needs a written reason; the old final is kept as *replaced* with that reason, never deleted.

Setup: create a Supabase project, run `supabase/schema.sql` in the SQL Editor, then add `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` to Vercel and redeploy. Without them the app works as before, just without records.

## How the login works

- `/` is served by `api/app.js`. Signed-out visitors get a sign-in page; signed-in users get the app.
- Signing in sets an HttpOnly, Secure session cookie for 12 hours. Changing `PAYROLL_PASSWORD` signs everyone out.
- `api/templates.js` returns the templates (from env vars) only with a valid session.
- `/?logout` signs out.

## Layout

```
api/app.js             login page + the app (after sign-in)
api/_page.js           the built app page (generated by src/build.py, no payroll data)
api/templates.js       templates for signed-in users only
api/_sealed.js         templates encrypted with AES-256-GCM (key: TEMPLATE_KEY env var)
api/records.js         save draft / mark final / reopen / list / download (Supabase)
lib/db.js              Supabase REST client (service_role key, server only)
supabase/schema.sql    table + one-final-per-month rule + locked-down access
api/version.js         public template fingerprint, for checking what's deployed
src/seal.mjs           re-encrypts private/ templates into api/_sealed.js
lib/auth.js            session cookie, password check
src/engine.js          calendar, payroll formulas, rounding, words, Excel/Word patching
src/app.src.html       UI source
src/build.py           builds api/_page.js (or a private offline copy with --offline)
test/regression.cjs    August 2026 must equal ₹2,49,199 (needs private/ templates)
private/               templates + offline copy. Git-ignored. Never commit.
```
